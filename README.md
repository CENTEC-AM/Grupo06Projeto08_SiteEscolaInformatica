# TechNova — Site para uma Escola de Informática

Projeto acadêmico desenvolvido com **HTML5, CSS3 e JavaScript**, seguindo a proposta do Projeto 8.

## Páginas
- Home
- Cursos
- Professores
- Calendário
- Contato

## Funcionalidades
- Cards de cursos
- Carrossel de depoimentos
- Modal com detalhes dos cursos
- Formulário de contato com validação HTML
- FAQ com `<details>`
- Botão de WhatsApp
- Filtro por categoria de curso
- Calendário interativo
- Menu responsivo para celular
- Layout responsivo

## Estrutura
```text
escola_informatica/
├── index.html
├── cursos.html
├── professores.html
├── calendario.html
├── contato.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Como executar
1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. Para editar o WhatsApp, abra `js/script.js` e altere `whatsappNumber`.
4. Para alterar nome, e-mail, cursos e datas, edite os arquivos HTML.

## Observação acadêmica
O nome "TechNova", professores, datas e contatos são fictícios e foram criados exclusivamente para demonstrar a aplicação das funcionalidades solicitadas.
